### 1.1 重点词群：native · domestic · exotic（本地 / 国内 / 驯养 ↔ 外来 / 国外 / 野生）

> 三个词分别对应"内 ↔ 外"对立的三个维度，阅读里常互为替换或互为反义，整组一起记。

| 维度 | "内 / 本地"一侧 | "外 / 外来"一侧 | 备注 / 来源 |
|---|---|---|---|
| 物种原产地 | ⭐ **native** (to) = **indigenous** (to) = endemic (to)（特有的，仅产于某地）= local | ⭐ **exotic** = non-native = alien = introduced = foreign (species)；invasive（入侵的，强调造成危害） | 生物 / 环境类核心对立；C13 p60 t3p1 |
| 国家范围 | ⭐ **domestic** = home = internal = national（domestic market / flights / demand） | foreign = international = overseas = external = from abroad | 经济 / 贸易类；C13 p60 t3p1 |
| 驯化状态 | **domesticated** = tame(d) = cultivated（植物）= farmed；domesticate v. → domestication n. 驯化 | wild = feral（家养后重新野化的）= untamed = uncultivated | 农业 / 动植物类；C13 p60 t3p1 |
| 各自其他义项 | native 还 = 天生的（native speaker 母语者；native ability 天赋），n. 本地人（a native of Paris）；domestic 还 = 家庭的、家用的（domestic appliances / violence） | exotic 还 = 奇异的、有异域风情的（exotic food / flavours） | 防止只记一个义项 |
| 共生、互利 | ⭐ symbiotic (relationship) = mutually beneficial = interdependent = of mutual benefit | C16 p41 t2p2 |
| 痴迷、沉迷 | ⭐ be obsessed with = have an obsession with / a fixation with / a preoccupation with = be fascinated by（程度弱）↔ indifferent（冷淡的） | C16 p41 t2p2 |
| 卫生 | hygiene = cleanliness；公共卫生 sanitation；反义 unhygienic / unclean | C16 p41 t2p2 |
| 微生物 | microbe = microorganism = germ（口语，含"病菌"色彩） | C16 p41 t2p2 |
| 猛增 ↔ 骤降 | ⭐ soar = skyrocket = surge = rocket = rise sharply / dramatically = increase steeply ↔ plummet = plunge = collapse = drop sharply | C16 p41 t2p2 |
| 特征 | ⭐ characteristics = features = traits = attributes = properties（物理属性） | C16 p47 t2p3 |
| 情景、设想 | scenario = (hypothetical) situation = contingency；in the worst-case scenario 在最坏情况下 | C16 p47 t2p3 |
| 公正 ↔ 偏袒 | ⭐ impartiality = impartial = fair = unbiased = even-handed = neutral ↔ partial = biased = prejudiced | C16 p47 t2p3 |
| 超过 | ⭐ exceed = surpass = go beyond = be in excess of | C13 p68 t3p3 |
| 突然的 ↔ 逐渐的 | ⭐ abrupt = sudden = swift = sharp ↔ gradual = slow = steady（气候 / 变化类判断题高频对立） | C13 p68 t3p3 |
